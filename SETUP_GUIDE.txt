QUICK START (Choose One Method)
================================================================================

METHOD 1: INSTANT (No Setup Required)
────────────────────────────────────
1. Find index.html in the folder
2. Double-click it or drag into browser
3. Done! Navigate using menu links

METHOD 2: PYTHON SERVER (Recommended - No Installation)
────────────────────────────────────
Windows (Command Prompt):
  cd path\to\globalacsic2026
  python -m http.server 8000

Mac/Linux (Terminal):
  cd path/to/globalacsic2026
  python3 -m http.server 8000

Then open: http://localhost:8000

METHOD 3: NODE.JS SERVER (If you have Node.js installed)
────────────────────────────────────
1. Install dependencies:
   npm install

2. Start server:
   npm start

3. Open browser:
   http://localhost:3000

METHOD 4: PHP SERVER (If you have PHP installed)
────────────────────────────────────
php -S localhost:8000

Then open: http://localhost:8000
